Guida alle directory:
- bubble_sort_SIMD: presenta il codice SIMD che implementa bubble sort
- parallel_bubble_sort_Base: Versione naive in Cuda bubble sort
- parallel_bubble_sort_Base_CoopGroups: Versione con Cooperative Groups Cuda
- parallel_bubble_sort_CG_Shared: versione con CG e Memoria shared in CUDA (finale)

In ognuna delle directory Cuda sono presenti dei test, che abbiamo usato nelle presentazioni e un file .txt con la configurazione per il lancio, oltre a un file di launch run.sh che è servito per il testing con blocchi di varie dimensioni.
